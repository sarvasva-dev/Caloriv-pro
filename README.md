The cross-platform mobile companion application for the **Caloriv** health suite. Empowers users to effortlessly log meals, calculate macronutrient ratios, monitor caloric intake, and achieve personalized fitness goals on the go.

---

## ⚡ Capabilities

- ⚡ **Rapid Meal Logging**: Clean, intuitive interface for logging breakfast, lunch, dinner, and snacks in seconds.
- 🎯 **Dynamic Macro Rings**: Real-time visualization of daily Protein, Carbohydrate, and Fat targets.
- 💧 **Hydration & Fasting Trackers**: Integrated water intake tracking and intermittent fasting timers.
- 📱 **Cross-Platform Delivery**: Single TypeScript codebase compiled for both Android and iOS devices using Expo.

---

## 🛠️ Tech Stack

- **Framework**: React Native, Expo SDK
- **Language**: TypeScript
- **State Management**: React Hooks & Context API
